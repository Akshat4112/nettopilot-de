# NP-CALC-013 — Private health and mandatory care insurance (2026)

**Status:** Implemented; CI verification required before merge  
**Assumption set:** `de-private-health-insurance-2026-v1`  
**Dependencies:** NP-RS-010, NP-CALC-005

## Module boundaries

- `private-insurance.ts` calculates **one** 2026 payroll month. It accepts separately sourced total health/care premiums, subsidy-eligible contributions, tax-eligible basic coverage, assessable income, employer-subsidy eligibility, employment state and actual payslip subsidies.
- `private-insurance-annual.ts` evaluates exactly **twelve** monthly inputs and sums the resulting cents; premiums, eligibility, state and payslip values may differ by month.
- `taxable-pay.ts` requires a **calculated** private-insurance result before preparing private PAP inputs. It verifies the gross private premiums match the current salary scenario, preventing a silent zero employer-subsidy placeholder from entering payroll tax.

### 2026 reference caps

The maximum comparison is computed each month using `min(assessable income, 581250 cents)`:

- Health: 8.75% of the base (maximum 50,859 cents).
- Private mandatory care, outside Saxony: 1.8% (maximum 10,463 cents).
- Private mandatory care, Saxony: 1.3% (maximum 7,556 cents).
- Each employer subsidy also cannot exceed 50% of the corresponding subsidy-eligible premium.
- Exact integer/BigInt cent calculations avoid binary floating-point cents drift.

These are employee employer-comparison limits, not unconditional flat subsidies.

### Payroll and cash semantics

An admitted private month returns `pap.PKV=1`, `pap.PKPV` from the **tax-eligible basic amount**, and `pap.PKPVAGZ` from the **actual or supported estimated tax-free employer subsidies**. Total premiums are not substituted for the tax-eligible basic amount.

The private premiums are an external cash outflow; no statutory employee GKV/PV deduction is generated by this module. `employeeAfterInsuranceCostCents` is premium less subsidy; when assembling payroll, ensure subsidies are counted exactly once.

### Fail-closed behavior

Return incomplete/unsupported instead of exact values for unknown eligibility, unconfirmed coverage, unknown employment state, disputed ELStAM, missing tax-eligible amount, missing assessable salary, unverified subsidy inputs, ineligible payroll subsidies and special-case treatment. Input money must be non-negative safe integer cents. The separate module has no medical-history inputs, network calls, storage or analytics.

### Explicit exclusions

Civil servants/Beihilfe, cross-border or foreign insurance, contribution refunds, claims, arrears, special employment, midijobs and mixed GKV/PKV are outside this calculation. Guided subsidies remain estimates, not claims of exact employer payroll.
